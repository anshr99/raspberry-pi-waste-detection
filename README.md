# Raspberry Pi Waste Detection

## Final Year Capstone Project

A real-time computer vision system designed to detect potential waste
objects using YOLOv5 Nano and OpenCV, with inference deployed on a
Raspberry Pi.

The project explores the use of lightweight deep learning models for
computer vision on resource-constrained edge devices.

## Key Features

- Real-time object detection
- YOLOv5 Nano
- OpenCV
- Raspberry Pi deployment
- Edge AI inference
- Bounding-box and confidence visualization
- Waste / non-waste categorization
